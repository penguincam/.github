# Security

Report a security issue privately. Do not open a public issue for it.

## How to report

- On a public repository, open the Security tab and choose "Report a
  vulnerability". Only the owner sees the report.
- Where that button is missing, open an issue in
  [penguincam/.github](https://github.com/penguincam/.github/issues) titled
  "Security contact request". Put no details in it. The owner replies with a
  private way to send them.

## What to include

- The repository and the commit or release you tested.
- What an attacker can do, and the steps to reproduce it.
- Any logs or output, with secrets and personal data removed.

## What happens next

The owner confirms the report, works on a fix and says when it ships. Please
keep the issue private until a fix is released. There is no bug bounty.
