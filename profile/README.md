# Penguin Cam

Penguin Cam builds camera hardware and software for solar-powered sites.
Penguin Interpreter is the software. Penguin Receiver is the hardware box.

## Start

Releases are public, and each release carries its complete source. Packages
and install steps arrive with the first release.

## Tasks

| Task | Where |
|---|---|
| Contribute a change | [Contributing guide](https://github.com/penguincam/.github/blob/main/CONTRIBUTING.md) |
| Report a security issue | [Security policy](https://github.com/penguincam/.github/blob/main/SECURITY.md) |
| Report a bug | The Issues tab of the repository |

## Contributing

Work from a fork named `<repo>-contrib` and send a pull request into `dev`.
The contributing guide has the steps.
